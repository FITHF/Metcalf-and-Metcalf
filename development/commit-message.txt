Implement Chunk 4: Case Management System

This commit implements the Case Management System for the Metcalf Legal Platform, which is Chunk 4 of the project roadmap. The implementation includes:

- Complete case creation and editing interface
- Interactive case timeline with milestone tracking
- Case status management and workflow automation
- Attorney assignment and collaboration features
- Case search and filtering capabilities
- Deadline tracking and reminder system

Backend Changes:
- Added new database tables for case management
- Created Metcalf_Case_Manager class for core functionality
- Implemented REST API endpoints for case operations
- Added WordPress admin integration

Frontend Changes:
- Created React components for case management interface
- Implemented interactive timeline visualization
- Added deadline management functionality
- Created API service for communication with backend

This implementation builds upon the existing foundation (Chunks 1-3) and provides a robust solution for law firms to manage their cases efficiently.
